# React 19 Component Generator Skill

## Purpose
Synthesize modular, accessible UI components matching the project's design system.

## Principles
1. Default to React Server Components (RSC) unless interactivity is strictly required.
2. Use Tailwind CSS utility classes; avoid custom CSS files.
3. Incorporate Lucide icons and clsx/tailwind-merge (`cn` utility).
4. Ensure responsive viewports (sm, md, lg, xl).
